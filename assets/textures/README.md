# Текстуры для игры Campfire

Поместите сюда PNG-файлы с соответствующими названиями, и они автоматически применятся в игре при следующем запуске:

- `player.png` — Игрок (Король)
- `tree.png` — Дерево (будет автоматически покачиваться на ветру с шейдером)
- `campfire.png` — Костер (бревна)
- `vagrant.png` — Бродяга
- `lumberjack.png` — Лесоруб
- `spearman.png` — Копейщик
- `wolf.png` — Волк
- `bear.png` — Медведь
- `wood.png` — Дрова
- `lumberjack_house.png` — Дом лесоруба
- `barracks.png` — Казарма
- `wall_construction.png` — Стройплощадка стены
- `wall_lvl1.png` — Стена 1 уровня (деревянная)
- `wall_lvl2.png` — Стена 2 уровня (каменная)
- `wall_lvl3.png` — Стена 3 уровня (шипастая)
