# Инструкция по расстановке объектов в Godot Editor

Добро пожаловать! Эта инструкция поможет вам самостоятельно оформить игровую сцену **`scenes/main/main.tscn`** в редакторе Godot 4.

Все игровые системы (время суток, найм, рубка, искусственный интеллект) автоматически адаптируются под объекты, которые вы перетащите на сцену.

---

## ⛺️ 1. Расстановка Костра (Campfire)

Костер — это центр вашей базы. Без него игра не начнется.

1. Во вкладке **FileSystem** (левый нижний угол Godot) найдите папку `res://scenes/campfire/`.
2. Перетащите файл **`campfire.tscn`** в окно дерева сцены (вкладка **Scene** слева) и отпустите его поверх корневого узла **`Main`**.
3. Убедитесь, что созданный узел в дереве сцены называется ровно **`Campfire`** (с заглавной буквы).
4. В 2D-редакторе переместите костер в центр вашего мира (например, в позицию `(x: 0, y: 0)` или рядом).

---

## 🌲 2. Расстановка Деревьев (Trees)

Деревья нужны игроку и лесорубам для добычи дров.

1. В FileSystem найдите папку `res://scenes/tree/`.
2. Перетащите файл **`tree.tscn`** на корневой узел **`Main`**.
3. Расставьте деревья по карте влево и вправо от костра.
4. **Быстрый способ сделать лес:**
   - Выберите любое дерево в дереве сцены.
   - Нажмите **Ctrl + D** (или **Cmd + D** на Mac), чтобы дублировать его.
   - Сдвиньте новое дерево в сторону. Повторяйте, чтобы быстро создать красивые рощи.

---

## 🏔 3. Настройка Параллакс-Фона (Background)

Чтобы за игроком двигались красивые горы и менялось небо:

1. Нажмите правой кнопкой мыши по узлу **`Main`** -> **Add Child Node** -> выберите **`Node2D`**.
2. Переименуйте созданный узел в **`Background`**.
3. В инспекторе справа найдите свойство **Z Index** (в разделе CanvasItem -> Ordering) и установите его в **`-100`** (чтобы фон рисовался позади персонажа).
4. Добавьте внутрь `Background` пять узлов типа **`Sprite2D`** (нажав правой кнопкой на `Background` -> *Add Child Node* -> *Sprite2D*). Настройте их следующим образом:

### Слой 1: SkyDay (Дневное небо)
* **Name**: `SkyDay`
* **Texture**: перетащите `res://assets/textures/небо_день.png`
* **Centered**: Включено (флажок стоит)
* **Texture Repeat**: `Enabled` (в разделе CanvasItem -> Texture -> Repeat)
* **Region Enabled**: Включено (в разделе Sprite2D -> Region)
* **Region Rect**: `Rect2(x: -100000, y: 0, w: 200000, h: 350)`
* **Position**: `x: 0, y: -525`
* **Scale**: `x: 1.5, y: 1.5`

### Слой 2: SkyNight (Ночное небо)
* **Name**: `SkyNight`
* **Texture**: перетащите `res://assets/textures/небо.png`
* **Centered**: Включено
* **Texture Repeat**: `Enabled`
* **Region Enabled**: Включено
* **Region Rect**: `Rect2(x: -100000, y: 0, w: 200000, h: 511)`
* **Position**: `x: 0, y: -320`
* **Scale**: `x: 1.5, y: 1.5`

### Слой 3: MountainsFar (Дальние горы)
* **Name**: `MountainsFar`
* **Texture**: перетащите `res://assets/textures/Горы_задний.png`
* **Centered**: Включено
* **Texture Repeat**: `Enabled`
* **Region Enabled**: Включено
* **Region Rect**: `Rect2(x: -100000, y: 0, w: 200000, h: 203)`
* **Position**: `x: 0, y: -110`
* **Scale**: `x: 1.2, y: 1.2`

### Слой 4: MountainsClose (Ближние горы)
* **Name**: `MountainsClose`
* **Texture**: перетащите `res://assets/textures/Горы.png`
* **Centered**: Включено
* **Texture Repeat**: `Enabled`
* **Region Enabled**: Включено
* **Region Rect**: `Rect2(x: -100000, y: 0, w: 200000, h: 229)`
* **Position**: `x: 0, y: -160`
* **Scale**: `x: 1.2, y: 1.5`

### Слой 5: ForestBack (Задний фон леса)
* **Name**: `ForestBack`
* **Texture**: перетащите `res://assets/textures/Деревья_заднийфон.png`
* **Centered**: Включено
* **Texture Repeat**: `Enabled`
* **Region Enabled**: Включено
* **Region Rect**: `Rect2(x: -100000, y: 0, w: 200000, h: 233)`
* **Position**: `x: 0, y: -130`
* **Scale**: `x: 1.2, y: 1.2`

## ☀️ 4. Настройка Солнца и Луны (CelestialLayer)

Чтобы солнце и луна двигались по небу в соответствии со временем суток:

1. Нажмите правой кнопкой мыши по узлу **`Main`** -> **Add Child Node** -> выберите **`CanvasLayer`**.
2. Переименуйте созданный узел в **`CelestialLayer`**.
3. В инспекторе справа установите его свойство **Layer** в **`-95`** (это расположит светила за деревьями и костром, но перед горами).
4. Добавьте внутрь `CelestialLayer` два узла типа **`Sprite2D`**:
   - **`SunSprite`**: перетащите текстуру `res://assets/textures/sun.png`
   - **`MoonSprite`**: перетащите текстуру `res://assets/textures/moon.png`

Скрипт игры сам найдет эти спрайты по именам и будет двигать их по круговой траектории.

---

## 🛖 5. Размещение Начальных Зданий и Стен (Опционально)

Вы можете сразу поставить игроку готовые строения, чтобы он не строил их с нуля:

* **Дом строителей**: Перетащите `res://scenes/buildings/builder_house.tscn` на `Main` и назовите его **`BuilderHouse`** (рекомендуемая позиция `x: -65`).
* **Дом лесорубов**: Перетащите `res://scenes/buildings/lumberjack_house.tscn` на `Main` и назовите его **`LumberjackHouse`** (рекомендуемая позиция `x: -130`).
* **Казармы**: Перетащите `res://scenes/buildings/barracks.tscn` на `Main` и назовите его **`Barracks`** (рекомендуемая позиция `x: 130`).
* **Деревянные стены**: Перетащите `res://scenes/buildings/wall.tscn` на `Main`. Назовите левую стену **`WallLeft`** (рекомендуемая позиция `x: -280`), а правую — **`WallRight`** (рекомендуемая позиция `x: 280`).
* **Башни лучников**: Перетащите `res://scenes/buildings/archer_tower.tscn` на `Main`. Назовите левую башню **`ArcherTowerLeft`** (рекомендуемая позиция `x: -240`), а правую — **`ArcherTowerRight`** (рекомендуемая позиция `x: 240`).

---

## 🏃‍♂️ 6. Размещение Начальных Бродяг (Опционально)

Если вы хотите, чтобы у костра в начале игры уже стояли бродяги, готовые к найму:

1. Добавьте узел **`Node2D`** в качестве дочернего для **`Main`** и назовите его **`InitialVagrants`**.
2. Внутрь `InitialVagrants` перетащите несколько экземпляров **`res://scenes/vagrant/vagrant.tscn`**.
3. Расставьте их вокруг костра (например, в позициях `x: -60` и `x: 70`).

---

💡 **Совет по проверке:** После того как вы расставите объекты в редакторе Godot, просто запустите игру (нажав **F5** или кнопку Play в правом верхнем углу). Все системы сразу начнут работать с расставленными вами объектами!
